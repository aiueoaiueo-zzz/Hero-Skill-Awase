# 決定事項（仕様書の補足・オーナー確認済み）

| # | 項目 | 決定 |
|---|---|---|
| A | 動画の必須／容量上限時の扱い | 動画は **常に必須**。容量上限（8-2）で動画の受付を停止している間は、投稿自体ができない（試作版どおり）。仕様書 8-2 の「文字だけの投稿は引き続き受け付ける」は適用しない。 |
| B | 初期キャラ | 試作版の 27 体を初期データとする（slug は仮。管理画面で変更可）。 |
| 14-1 | キャラ画像の権利 | オーナーが確認する。実装は画像アップロード＋頭文字表示の両対応。 |
| 14-2 | 独自ドメイン | 当面使わない。`*.workers.dev` で運用し、動画は Worker 経由で配信。`MEDIA_BASE_URL` で切替可能にしておく。 |
| 14-3 | ゲーム画面の動画の権利 | オーナーが確認する。 |
| 14-4 | 14 日以上審査されない動画 | 残す（環境変数の初期値も「残す」）。 |
| 14-5 | 注意事項・「このアプリについて」の文面 | 試作版の文面をそのまま初期値とする。 |
| C | 管理画面の守り方 | workers.dev では Access をパス単位にできないため、同じソースを **管理用の Worker（hs-awase-admin）** としてもう 1 つデプロイし、そのアドレス全体を Access で保護する（Worker 側の JWT 検証も継続）。一般向けの Worker には管理画面・管理 API を置かない。`APP_ROLE` で切り替え。 |
| D | 進捗バーの色 | 動画の変換・アップロードの進捗バーは **オレンジ一色**（試作版のオレンジと水色の縞模様から変更）。 |
| E | 変換・アップロード中に画面を離れたとき | iPhone のブラウザは裏に回ったページの処理を止めるため、バックグラウンドでの継続はできない。代わりに、処理中は画面の自動ロックを防ぎ（Wake Lock）、切り替えて戻ったら WebCodecs で自動的にやり直す。アップロードは「再試行」で続きから送れる。 |
| F | X への共有・処理中の表示・審査状況の折りたたみ | オーナーの要望で追加（仕様書にはない機能）。①詳細画面の各タイミングに「共有」（X に投稿／X の DM／LINE／リンクをコピー／その他のアプリ）（リンクは `/h/攻撃側/相手#t-タイミングID` で、そのタイミングのタブを開いて移動・強調）。②管理画面で承認したタイミングに「共有」（同じメニュー）（文面：この合わせがアップロードされました／投稿者／応援コード）。③承認・却下・編集して承認の処理中は回転アイコンを表示。④審査状況の承認済みタイミングは ▶／▼ で折りたたみ（最初は折りたたみ）。 |
| G | アドレスと共有リンク | workers.dev のサブドメインを `cmps` に変更（アプリ `hs-awase.cmps.workers.dev`／管理画面 `hs-awase-admin.cmps.workers.dev`）。共有リンクは短いリンク `/s/<6文字のコード>` にし、開くとそのタイミングへ移動する。コードは承認時に発行（それ以前に承認されたものは最初に表示されたとき）。修正提案を承認しても元のタイミングのコードは変わらない。 |
| H | 公開後の管理・入力の保持・修正後の投稿者名 | ①管理画面に「公開中」タブを追加し、公開中のタイミングを「非公開にする（動画も pending/ に戻して見えなくする）／公開に戻す／削除」できるようにした。②投稿フォームの入力（文字・選択・手順）をタブの sessionStorage、変換後の動画を IndexedDB に保存し、ページを読み込み直しても戻す（24 時間・申請完了で消去）。③修正提案を承認したら、表示する投稿者（ニックネーム・応援コード）を **修正した人** にする（credit_submission_id）。 |
| I | 新しい投稿の通知 | Discord の Webhook に通知する（`DISCORD_WEBHOOK_URL`、任意）。新しい投稿・修正提案のたびに 1 件、容量の上限で受付が止まったときは 12 時間に 1 回まで。メンションは一切飛ばさない。 |
| J | アプリのアイコン | 案 2-A「HS合わせ」（オレンジ地に黒の「HS」、黒帯に白の「合わせ」、角を斜めに切った形）。ホーム画面に追加したときの名前は「HS合わせ」、テーマ色はオレンジ。元データは docs/icon/。 |
| K | セキュリティの追加対策 | 署名付きアップロード URL に Content-Length も含め、申告と違うサイズのファイルは R2 に置けないようにした。全画面にセキュリティ用のヘッダー（埋め込み禁止・nosniff など）を付けた（Worker と public/_headers）。 |
| L | 注意事項・お問い合わせ | 「注意事項・プライバシー」（/terms、文面は管理画面の設定で変更可）と「お問い合わせ」（/contact、Turnstile 必須、D1 に保存して Discord に通知、管理画面の「問い合わせ」タブで対応済み・削除。対応済みは 90 日後に自動削除）を追加。フッターの注意書きは 2 行に減らし、「注意事項・プライバシー」「お問い合わせ」へのリンクを置いた（「このアプリについて」はヘッダーの「ⓘ 概要」と同じなので置かない）。注意事項は最低限の内容に絞った。管理画面の「問い合わせ」タブに未対応の件数を出す。 |
| N | 画面の切り替え | 相手の選択画面は、登録済みの組み合わせを最初の読み込み（/api/bootstrap）で受け取り、通信を待たずに表示する。詳細画面は、キャラをタップした瞬間にデータを読み始め（60 秒キャッシュ）、見出しと VS は待たずに表示する。起動演出は、データが届いたときに新しく出た部分だけ再生する。 |
| O | お問い合わせの種類 | 「ご要望」を追加（migration 0008）。内容は 5 文字以上必須で、その旨をフォームに表示する。 |
| P | キャラの入れ替え | 試作版の 27 体をすべて削除し、オーナー指定の実装順の 100 体に入れ替え（migration 0009）。その後 hero-49〜52 に 4 体（アイズ・甘色・ノクティス・ニーズヘッグ）を追加し、以降を 4 つ後ろにずらした（migration 0010、計 104 体）。slug は実装順に hero-1〜hero-104、並び順も同じ。キャラ名は短い呼び名（例：アタリ、ジャンヌ）。画像がないときの頭文字の表示は、「13」「2B」「GBG」のような短い英数字の名前なら名前をそのまま出す。 |
| Q | 非公式の表示・権利表記 | 全画面のヘッダー右上に小さく「非公式ファンツール」（管理画面では出さない）。フッターに「©NHN PlayArt Corp. ©DWANGO Co., Ltd.」を固定で表示し、最下行は「HS明け早見アプリ（非公式ファンツール）」。 |
| R | アプリの名称・収益 | 名称を「HS明け早見アプリ」から「HS合わせアプリ」に変更（画面・ページタイトル・ホーム画面の名前・共有の文面とハッシュタグ #HS合わせアプリ）。注意事項に「収益を目的としていない（広告・有料機能なし）」を明記。仕様書（SPEC.md）と試作版は当時の名称のまま残す。 |
| S | キャラ画像を使わない | 権利への配慮から、一般向けの画面ではキャラ画像を表示しない。代わりにグレーの背景に白い文字でキャラ名を全部出すカード。一般向けの API は imageUrl を返さず、/media/heroes/ も一般向けの Worker では配信しない（管理画面のキャラ管理だけ画像を確認・削除できる）。 |
| T | キャラの正式名称 | heroes.full_name（任意、migration 0011）。カードには短い名前（name）、カードの下・詳細の VS・キャラ選択には正式名称（未設定なら name）を出し、検索はどちらでも当たる。管理画面のキャラ管理で入力（空にすると未設定）。保存済みのキャラ画像は 104 体分すべて削除済み（データの確認・削除の delete-hero-images）。 |
| M | ヘッダーのアイコン | 全画面のヘッダーにアプリのアイコンを置き、タップで最初の画面へ戻る（管理画面では承認待ちへ）。戻るボタンはそのまま残す。 |
| - | 背景の照準リングの回転 | 試作版の最終 CSS どおり 4 分で 1 回転（10-3-2 の 90 秒ではなく 10-3-4 に合わせる）。 |
