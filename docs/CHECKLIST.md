## そのほか確認したこと

- `prefers-reduced-motion: reduce` で、すべてのアニメーションが止まる
- キーボード操作時のフォーカスはオレンジの枠。検索欄をタップしても枠は出ない
- Turnstile：本番ホストでキー未設定のときは投稿を拒否（設定漏れで素通りしない）。本物の Turnstile 画面は本番で確認
- 毎日の自動処理：不要ファイルの削除、容量の照合、14 日以上の承認待ち（keep / delete）

## 本番で最初に確認すること（README 3 章の手順のあと）

1. 管理画面の URL を開くと Access のログイン画面が出て、ログイン後に管理画面が表示される
2. アプリの URL の `/admin` が 404
3. 投稿フォームに Turnstile が表示され、申請できる
4. 動画のアップロードが R2 に直接届く（ブラウザの開発者ツールで `r2.cloudflarestorage.com` への PUT が 200）
5. 管理画面で承認すると、詳細画面で動画が再生できる
6. 翌日、Workers のログに `maintenance {...}` が出ている
